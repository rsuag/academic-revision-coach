# Profile Extraction Rules

## Evidence Thresholds

- `high`: the same preference appears in three or more independent edits, or the author explicitly confirms it.
- `medium`: the preference appears twice in the same document type without a counterexample.
- `low`: one occurrence, ambiguous rationale, or conflicting evidence. Keep as a candidate only.

## Scope Before Generalization

Assign the narrowest valid scope: `response letter`, `cover letter`, `manuscript prose`, `supporting information`, or `all submission materials`. A response-letter preference never automatically applies to manuscript interpretation.

## Counterexamples

When a mentor accepts the wording that another edit rejects, record both source IDs and mark the rule `conditional`. Ask the author to decide the trigger condition. Never resolve the conflict by majority vote alone.

## Learning Updates

Only save a new rule after the author explicitly approves it. An accepted suggestion is evidence, not automatic consent to change a persistent profile.
